AI Engine
How the Agent Thinks
A multi-step pipeline converts your words into a working workspace.
Intent → Action Pipeline
1. Intent Classification
Conservative regex + contextual rules classify the prompt as: chat, build, or refine. Only explicit build verbs trigger project generation — avoiding accidental builds from casual questions.
2. Blueprint Selection
The LLM picks one of 8+ blueprints (react-app, flask-api, saas-dashboard, full-stack, etc.) based on the user's description.
3. Agentic Tool Loop
AgentRuntime iterates: list_files → read_file → write_file → validate using the LLM to decide what to do next at each step. Up to 24 iterations per build.
4. Conversation Memory
Up to 40 prior messages are serialised and injected into every LLM call — so refinement requests remember your original design preferences.

Security
Built to Be Safe
Security was designed in from day one — not added as an afterthought.
🔐
JWT Authentication
7-day expiring tokens, signed with a secret key. Every protected route validates the bearer token before responding.
PyJWT Bearer tokens
🏖️
Sandboxed Execution
User-submitted code runs in an isolated subprocess with a hard 10-second timeout. stdout/stderr are captured cleanly.
subprocess 10s timeout
🛤️
Path Traversal Guard
All file operations validate that the resolved path starts with the workspace directory. No escape to the host filesystem.
os.path.abspath 403 guard
🔒
Password Hashing
Passwords are hashed with Werkzeug's PBKDF2-SHA256 before storage. Plain text passwords never touch the database.
Werkzeug PBKDF2
🚦
Rate Limiting
Sliding-window rate limiter on the AI endpoint: max 10 requests per minute per IP. Blocks abuse without third-party middleware.
10 req/min per-IP
🌐
CORS Policy
Strict allowlist of origins (localhost:5173–5175 only). No wildcard `*` — requests from unknown origins are rejected.
Flask-CORS allowlist
