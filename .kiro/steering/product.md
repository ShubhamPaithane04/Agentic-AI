# Product Overview

This is an AI-powered development assistant platform that provides intelligent code generation, debugging, planning, and testing capabilities through specialized agents.

## Core Features
- **Multi-Agent Architecture**: Specialized agents for different development tasks (coder, debugger, planner, tester)
- **Web Interface**: Frontend for user interaction and project management
- **Project Generation**: Automated project scaffolding and code generation
- **Development Workflow**: End-to-end support from planning to testing

## Target Users
Developers seeking AI assistance for code generation, debugging, project planning, and automated testing workflows.
